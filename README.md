# ঢাকার বাস বস — Dhaka Bus Boss 3D 🇧🇩
### স্লোগান: “জ্যাম আমার, রাস্তা সবার!”

একটি সম্পূর্ণ ৩ডি ব্রাউজার আর্কেড ড্রাইভিং গেম, যেখানে আপনি ঢাকার রাজপথে লোকাল বাস চালাবেন, যাত্রী তুলবেন, সিএনজি ও রিকশার জ্যাম কাটাবেন, হর্ন দিয়ে রাস্তা খালি করবেন এবং ঢাকার সেরা ‘বাস বস’ হয়ে উঠবেন!

---

## 🎮 গেমের বৈশিষ্ট্যসমূহ (Features)

- **সম্পূর্ণ ৩ডি ঢাকার পরিবেশ (Full 3D Dhaka Streetscape):**
  - চার লেনের ব্যস্ত ঢাকা এভিনিউ, রোড ডিভাইডার ও লেন মার্কিং।
  - মাথার উপর দিয়ে যাওয়া মেট্রোরেল ভায়াডাক্ট (Metro Rail Overhead Viaduct)।
  - সবুজ সিএনজি অটোরিকশা (CNG Auto-rickshaws) — হর্ন শুনলেই সাইড কাটে!
  - প্যাডেল চালিত সাইকেল রিকশা (Cycle Rickshaws) ও রঙিন হুড।
  - প্রাইভেট কার, হলুদ ট্যাক্সি ও অন্যান্য লোকাল বাস।
  - রাস্তার পাশে টং দোকান (Tong Tea Stalls with kettles), বিলবোর্ড (কাচ্চি ভাই বিরিয়ানি, মেগাবাইট অফার ইত্যাদি) ও বহুতল আবাসিক ভবন।

- **আসল লোকাল বাসের মেকানিক্স (Gameplay Mechanics):**
  - **যাত্রী ওঠানো ও ভাড়া আদায় (Passenger Pickup):** ফার্মগেট, কারওয়ান বাজার, শাহবাগ, প্রেসক্লাব, পল্টন, গুলিস্তান, মতিঝিল ইত্যাদি স্টপে হলুদ মার্ক করা জোনে গতি কমিয়ে (২০ কিমি/ঘণ্টার নিচে) দাঁড়ান। সহকারী যাত্রী তুলবে এবং আপনি নগদ ভাড়া (৳) ও পয়েন্ট পাবেন।
  - **কাছাকাছি ওভারটেক (Near-Miss Overtakes):** সিএনজি ও প্রাইভেট কারের কোল ঘেঁষে জ্যাম কাটালে ‘কাছাকাছি ওভারটেক! +৳৫০’ ক্যাশ বোনাস ও পয়েন্ট মাল্টিপ্লায়ার পাওয়া যায়।
  - **কিংবদন্তি বাস হর্ন (Legendary Horn):** `H` বা অন-স্ক্রিন হর্ন বাটন চাপলে ক্লাসিক ডাবল-টোন এয়ার হর্ন, মিউজিক্যাল ফ্যানফেয়ার বা স্ট্যাকাটো হর্ন বাজে এবং সামনের ট্রাফিক সরে গিয়ে রাস্তা ক্লিয়ার করে!
  - **ক্ষতি ও মেরামত (Damage System):** দেয়ালে বা গাড়িতে ধাক্কা লাগলে বাসের ক্ষতি বাড়ে। ১০০% ক্ষতি হলে খেলা সমাপ্ত হবে।

- **মজার খাঁটি বাংলা ডায়লগ ও ভয়েস (Authentic Bangla Comedy & Voice):**
  - হেলপার, যাত্রী, ড্রাইভার ও ট্রাফিকের ৪০+ মৌলিক হাসির বাংলা ডায়লগ।
  - ব্রাউজার স্পিচ সিন্থেসিসের মাধ্যমে বাংলা ভয়েস প্লেব্যাক (সাপোর্টেড ডিভাইসে) এবং সুন্দর কমিক স্পিচ বেলুন।
  - ওয়েব অডিও এপিআই (Web Audio API) সিন্থেসাইজারে তৈরি ডিজেল ইঞ্জিনের গর্জন, এয়ার ব্রেকের হিস হিস শব্দ, ট্রাফিক সংঘর্ষ ও ধাতব পয়সার আওয়াজ।

- **বাস গ্যারেজ ও আনলকযোগ্য ৬টি লোকাল বাস (Bus Garage):**
  1. **সবুজ সাথী (Green Pioneer)** — ক্লাসিক ঢাকা লোকাল
  2. **লাল-নীল বুলেট (Red-Blue Bullet)** — গতি আর সাহসের প্রতীক
  3. **ভিআইপি লোকাল (VIP Local)** — ভাঙা সিটে রাজকীয় ভ্রমণ
  4. **জ্যাম খাদক (Jam Destroyer)** — ট্রাফিকের বুক চিরে এগিয়ে চলা দৈত্য
  5. **নাইট রাইডার ঢাকা (Midnight Dhaka)** — ফাঁকা ভিআইপি রোডের রাজা
  6. **সোনার বাংলা বস (Golden Bus Boss)** — রাজপথের আসল মহারাজ

- **মোবাইল ও পিসি উভয়ের জন্য পারফেক্ট (Responsive Controls):**
  - পিসিতে কীবোর্ড কন্ট্রোল এবং মোবাইলের জন্য বড় টাচ স্টিয়ারিং প্যাড ও গ্যাস-ব্রেক প্যাডেল।
  - লোকাল স্টোরেজে (localStorage) সেরা স্কোর, জমানো টাকা ও আনলক করা বাস সংরক্ষিত থাকে।

## 🕹️ কীভাবে খেলবেন (Controls)

### ডেস্কটপ / ল্যাপটপ (Keyboard):
- **W / ⬆️ Up Arrow:** এক্সিলারেট (গতি বাড়ানো)
- **S / ⬇️ Down Arrow:** ব্রেক ও গতি কমানো
- **A / ⬅️ Left Arrow:** বামে স্টিয়ারিং
- **D / ➡️ Right Arrow:** ডানে স্টিয়ারিং
- **Space:** ইমার্জেন্সি হ্যান্ডব্রেক
- **H:** বিখ্যাত লোকাল বাস হর্ন
- **Esc / P:** গেম পজ করা
- **Enter / Space:** টাইটেল স্ক্রিন থেকে খেলা শুরু

### মোবাইল / ট্যাবলেট (Touch Controls):
- স্ক্রিনের বাম দিকের বড় **বামে (⬅️) ও ডানে (➡️)** বাটন চেপে স্টিয়ারিং করুন।
- স্ক্রিনের নিচে বড় লাল **হর্ন (📢 H)** বাটন চেপে হর্ন বাজান।
- ডান দিকের সবুজ **গ্যাস (W)** ও লাল **ব্রেক (S)** প্যাডেল দিয়ে গতি নিয়ন্ত্রণ করুন।

## 🛠️ প্রযুক্তি ও আর্কিটেকচার (Tech Stack)

- **ফ্রেমওয়ার্ক:** React 19 + TypeScript + Vite
- **৩ডি গ্রাফিক্স:** Three.js (Procedural geometries, low-draw call pooling, PBR materials with RoomEnvironment reflections)
- **শব্দ ও অডিও:** Web Audio API Procedural Synthesizer + Web Speech API (Bengali voices)
- **স্টাইলিং:** Tailwind CSS
- **ইউনিট টেস্ট:** Node.js Built-in Test Runner (`node:test`, `node:assert/strict`)

## 🚀 ডিপ্লয়মেন্ট ও পাবলিক শেয়ারিং (Deployment Guide)

প্রজেক্টটি একটি স্ট্যান্ডার্ড Vite React SPA হিসেবে তৈরি করা হয়েছে এবং যেকোনো স্ট্যাটিক হোস্টিং প্ল্যাটফর্মে সরাসরি রান করে।

### ১. লোকাল ডেভেলপমেন্ট:
```bash
npm install
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:3000`

### ২. প্রোডাকশন বিল্ড:
```bash
npm run build
```
এটি অপ্টিমাইজড স্ট্যাটিক ফাইলগুলো `dist/` ফোল্ডারে জেনারেট করবে।

### ৩. Vercel বা Netlify-তে ডিপ্লয়:
1. কোডটি GitHub রিপোজিটরিতে পুশ করুন।
2. **Vercel** অথবা **Netlify**-তে গিয়ে `Import Project` নির্বাচন করুন।
3. Build Settings:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Deploy বাটনে ক্লিক করলেই কয়েক সেকেন্ডে সম্পূর্ণ গেমটি লাইভ হয়ে যাবে!
